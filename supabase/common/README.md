# Миграции для всех языков (применяются к каждому разделу из langs.json после его собственной цепочки).

- `20261031090000_admin_tools.sql` — «Одобрить все» в проверке вопросов; сообщения пользователям (таблица `announcements`).
- `20261101090000_sync_old_apps.sql` — перенос прогресса и подписок из старых приложений (`sync_snapshot`, `sync_apply`, триггер первого входа); см. `scripts/sync/README.md`.
- `20261108090000_announce_once.sql` — сообщения пользователям: рассылка «во все языки» показывается человеку один раз (общая таблица `shared.ann_seen`); непрочитанные — каруселью от старого к новому (`get_announcements`, `mark_announcements_seen`).
- `20261109090000_announce_existing_only.sql` — сообщения видят только те, кто уже был учеником в момент отправки (для «во все языки» — учеником любого языка, `shared.user_since`).
- `20261110090000_look_kids.sql` — «Оформление» (`set_look`: скругление, иконки, картинки к словам) и детский режим (ПИН-код, сброс через бота, слова, прогресс, «Успехи»).
