# Синхронизация со старыми приложениями

Переносит учебный прогресс и подписки из отдельных приложений (старый армянский и старый узбекский боты)
в разделы `hy` и `uz` Polytutor. Пользователи сопоставляются по Telegram ID.

- **Когда:** раз в неделю (задача «Синхронизация со старыми приложениями», понедельник 07:23 по Ташкенту) и при
  первом входе в Polytutor — из последнего недельного снимка. Вручную: Actions → эта задача → Run workflow.
- **Что переносится:** уровни слов, предложения и формы, марафон, статистика по дням, сданные тесты уровня,
  прогресс тем курсов (сопоставление по курсу и номеру темы), очередь слов из тем, настройки, действующие подписки.
- **Правило:** остаётся то, что дальше; прогресс, сделанный в Polytutor, не откатывается.
- **Подписки:** копируются отдельными записями (`source = 'manual'`, `source_ref = 'sync:<id>:<конец>'`).
  Продление или возврат в старом приложении меняют их при следующей синхронизации.
- **Старые базы только читаются:** пользователь `tutor_sync` в режиме «только чтение», доступ — к 11 таблицам.

Файлы: `old_readonly_role.sql` (один раз в SQL Editor старого проекта), `export_old.sql` (снимок),
`sync_old.sh` (снимок → `<язык>.sync_snapshot` → `sync_apply_all()`), миграция
`supabase/common/20261101090000_sync_old_apps.sql`.
